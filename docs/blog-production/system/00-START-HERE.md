# There & Back Again — Claude Blog Production System

This package sets Claude Code up to research, draft, QA and integrate new destination-cluster articles without flattening the site into generic travel content.

## Recommended use

1. Copy this folder into the root of the There & Back Again repository as `docs/blog-production/`.
2. Open Claude Code in the repository.
3. Paste the contents of `CLAUDE-KICKOFF-PROMPT.md`.
4. Claude must inspect the repository before changing content.
5. The first pilot is the Seville cluster. Claude stops after the research packet and outline for approval.
6. After the pilot article is approved, continue one article at a time. Move to batches of no more than three only after the format is stable.

## Source hierarchy

1. Existing There & Back Again articles and the user's supplied trip material for personal experience.
2. Official tourism, transport, heritage, museum, venue and government sources for current facts.
3. Reputable specialist/editorial sources for context.
4. Maps and review platforms only as secondary corroboration.

Claude must never invent first-person experience, transport taken, meals eaten, accommodation used, prices paid or emotional reactions.
